Concept

"When this happens, run this code"

Some properties don't take a value. They take a function: code to run later.

When the text changes…

onChanged: (value) {
  print(value);
},

Flutter gives you the new text as value.

When the button is tapped…

onPressed: () {
  print('Tapped!');
},

Empty (): no extra information needed.

Read (value) { … } as: "take value, then do what's inside the { }".
Mobile App Development · Lecture 07

These are functions without a name (anonymous functions). Don't use the term yet; the "when this happens, run this" idea is enough for beginners.

Troubleshooting

4 input mistakes (and the fix)

No Material widget found.Put the TextField inside a Scaffold.
An InputDecorator … cannot have an unbounded width.A TextField in a Row needs Expanded around it.
Bottom overflowed by 120 pixels.The keyboard covers the screen. Fix next lecture with SingleChildScrollView.
The button is grey and doesn't workonPressed is null. Give it a function: () { }
