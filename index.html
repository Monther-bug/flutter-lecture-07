Assets · Step 1 of 3

Make an assets folder

Assets are files that ship inside your app: pictures, icons, fonts. They work without internet.

my_first_app/
├─ assets/★ new folder
│ └─ images/★ new folder
│ ├─ logo.pngyour pictures
│ └─ me.jpg
├─ lib/
└─ pubspec.yamlnext step

Right-click the project

In VS Code: right-click the project name → New Folder → assets, then images inside it.

Drag your pictures in

Use simple names: lowercase, no spaces. me.jpg ✓   My Photo (1).JPG ✗

Mobile App Development · Lecture 07

The assets folder goes in the project root, next to lib, not inside lib.

Assets · Step 2 of 3

Tell Flutter in pubspec.yaml

pubspec.yaml
flutter:
  uses-material-design: true
  assets:
    - assets/images/
assets:The list of asset folders or files
- assets/images/Everything in this folder. Don't forget the / at the end!
Spaces matter! assets: has 2 spaces, - assets/… has 4.
Save the file. VS Code runs flutter pub get for you.
Mobile App Development · Lecture 07

In the default pubspec.yaml there's a commented-out "assets:" example. Students can uncomment it, but they must fix the indentation.

Copy the path straight from VS Code (right-click the file → Copy Relative Path) to avoid typos. On Windows, change the backslashes to forward slashes.

Image tip

fit: how a picture fills its box

Same picture, same square box, three different BoxFit values:

BoxFit.coverFills the box, cuts the edges
BoxFit.containShows all of it, leaves space
BoxFit.fillStretches it (can look wrong!)
Mobile App Development · Lecture 07

BoxFit.cover is the one used most for photos. contain is good for logos.

Widget 3 · Round images

CircleAvatar and ClipRRect

CircleAvatar
a round photo

CircleAvatar(
  radius: 50,
  backgroundImage: AssetImage('assets/images/me.jpg'),
)

ClipRRect
rounded corners

ClipRRect(
  borderRadius: BorderRadius.circular(16),
  child: Image.asset('assets/images/me.jpg'),
)
Inside CircleAvatar use AssetImage(…) or NetworkImage(…), not Image.asset.
Mobile App Development · Lecture 07

ClipRRect = "Clip Rounded Rectangle". It cuts its child into a rounded shape. CircleAvatar is perfect for profile pictures.

Bonus · SVG images

SVG pictures need a package

SVG images stay sharp at any size. Flutter can't show them alone, so we add flutter_svg.

1 · Add the package
Terminal
PS> flutter pub add flutter_svg
2 · Import it 
import 'package:flutter_svg/flutter_svg.dart';
3 · Use it 
SvgPicture.asset(
  'assets/images/logo.svg',
  width: 80,
)
A package is ready-made code from pub.dev. This is our first one!
Mobile App Development · Lecture 07

After flutter pub add, open pubspec.yaml and show the new line under dependencies. Free SVG icons: svgrepo.com, undraw.co.

Troubleshooting

4 image mistakes (and the fix)

Unable to load asset: "assets/images/me.jpg"Check the path and file name, and that the folder is listed in pubspec.yaml.
New picture doesn't show upStop the app and run it again. New assets need a full restart.
Error on line 12, column 4 … pubspec.yamlWrong spaces in pubspec.yaml. Use 2 and 4 spaces, never Tab.
SocketException: Failed host lookupNo internet, or a wrong URL in Image.network.
Names are case-sensitive: Me.JPG and me.jpg are two different files.
Mobile App Development · Lecture 07

"Unable to load asset" is the number one image error. Go through the checklist with the class: folder, pubspec, exact name, restart.
